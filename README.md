## Systems, not demos.

Models answer questions. Systems finish work.

I care about the second problem: how agents divide work, preserve context across long-running tasks, and act through tools. The projects here are my answers to those problems.

| Collaboration | Continuity | Action |
|---------------|------------|--------|
| Multi-agent coordination, asynchronous orchestration, and AG-UI interaction | Long-term memory, context management, retrieval, and state recovery | MCP tools, service registration, SDKs, and runtime infrastructure |

Together, these capabilities get closer to what I mean by superintelligence: not better at talking, but better at acting.

## Selected builds

These are not theme projects. Each one tackles a concrete problem in collaboration, continuity, or action.

| Project | What it does |
|---------|--------------|
| [multi-agent](https://github.com/SiAgentBuild/multi-agent) | Runs multiple agents asynchronously in one backend and exposes execution state through AG-UI |
| [NacosX](https://github.com/SiAgentBuild/NacosX) | Lets Python services register, send heartbeats, and shut down gracefully as part of a long-running system |
| [httpxodus](https://github.com/SiAgentBuild/httpxodus) | Handles HTTP ecosystem migrations, the unglamorous work that determines how long systems survive |
